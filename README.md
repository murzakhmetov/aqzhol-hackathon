## 📌 О проекте

**Aqzhol** — автоматизированная платформа для анализа состояния автомобильных дорог. С помощью технологий компьютерного зрения на базе PyTorch и больших языковых мультимодальных моделей (VLM) от Groq система находит, классифицирует трещины и формирует детальный отчет для диспетчеров и ремонтных служб. 

Наша миссия: **предупредить образование ям до того, как о ни разрушат дорожное полотно**, экономя бюджетные средства и повышая безопасность на дорогах.

### 🔥 Ключевые возможности

* **Детекция с помощью DeepCrack (PyTorch)**: Точное попиксельное нахождение трещин сложной формы.
* **Глубокий анализ через Groq (Llama Vision)**: Оценка типа трещины (продольная, поперечная, сетка), степени опасности, примерной стоимости ремонта и сроков.
* **Система умных рекомендаций**: Формирование текстового заключения для дорожных служб.
* **Диспетчерская панель**: Интерактивный React-интерфейс с журналом проверок, аналитикой и выгрузкой отчетов.
* **Обработка чистых участков**: Умное распознавание участков без видимых проблем (статус «Трещины не обнаружены»).

## 💻 Установка и локальный запуск (Localhost)

Ниже приведены подробные инструкции по запуску проекта на Windows и Linux (Ubuntu).

### Подготовка

1. Убедитесь, что у вас установлен **Python 3.10+**.
2. Убедитесь, что установлены **Node.js** и **npm** (для запуска React фронтенда).
3. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-репозиторий/Aqzhol_Decentrathon_5.0.git
   cd Aqzhol_Decentrathon_5.0
   ```
4. **ВАЖНО**: Скопируйте файл весов модели `pretrained_net_G.pth` в корневую директорию проекта, иначе сервер FastAPI не сможет инициализировать нейросеть DeepCrack.

---

### Шаг 1. Запуск Backend (FastAPI + PyTorch)

#### На ОС Windows:
```cmd
# Рекомендуется создать виртуальное окружение
python -m venv venv
venv\Scripts\activate

# Установка зависимостей
pip install torch torchvision opencv-python-headless imutils scipy pillow fastapi uvicorn httpx python-multipart pydantic python-dotenv

# Запуск сервера
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

#### На Linux (Ubuntu):
```bash
# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install torch torchvision opencv-python-headless imutils scipy pillow fastapi uvicorn httpx python-multipart pydantic python-dotenv

# Запуск сервера
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```
✅ **Backend API** будет доступно по адресу: `http://127.0.0.1:8000`  
Документация Swagger (тестирование эндпоинтов) доступна по адресу: `http://127.0.0.1:8000/docs`

---

### Шаг 2. Запуск Frontend (React.js)

Не закрывая окно терминала с сервером Python, откройте **новую вкладку терминала**.

#### Для Windows и Linux:
```bash
cd web-deepcrack

# Установка npm-зависимостей
npm install

# Запуск React-сервера для разработки
npm start
```
✅ После запуска браузер автоматически откроет клиентское приложение по адресу: **`http://localhost:3000`**

## 🛠 Конфигурация / Переменные окружения

Все API-ключи и конфигурационные данные вынесены в файл `.env`.
При первом запуске скопируйте шаблон:
```bash
cp .env.example .env
```
Затем откройте файл `.env` и впишите туда свои ключи:
* `GROQ_API_KEY`: Ваш персональный ключ от Groq Cloud (для работы LLM анализа).
* `SUPABASE_URL` и ключи `SUPABASE_*`: Данные для подключения к облачной БД для хранения истории анализов.

## 📖 Руководство пользователя (Как пользоваться)

1. Откройте интерфейс диспетчера `http://localhost:3000`.
2. В интерфейсе выберите **фотографию** участка дороги с потенциальными ямами или трещинами (JPG / PNG).
3. При необходимости укажите физические **метрики** (ширина изображения, например `2.5 м`) в настройках для точного подсчета ширины трещин алгоритмом.
4. Нажмите кнопку **"Анализировать" (Predict)**.
5. Подождите несколько секунд. Backend прогонит изображение через PyTorch и свяжется с облаком Groq.
6. Вы получите **изображение с нанесенными контурами** трещин, их процентное покрытие, а также подробный **ИИ-отчет**:
    * Классификация трещины
    * Уровень риска (1-10)
    * Рекомендации по срочному ремонту
    * Примерную смету (стоимость)

## 📡 API Эндпоинты

Пример работы основных маршрутов Backend (можно тестировать через Postman):
* `GET /health` — Статус работоспособности сервера и моделей (Healthcheck).
* `POST /analyze` — Основной эндпоинт. Принимает `multipart/form-data` с картинкой и метаданными, возвращает JSON c вердиктом `DeepCrack` и `Groq API`.
* `GET /history` — Возвращает историю предыдущих загрузок и анализов.
* `GET /history/export/text` — Выгрузка простого текстового отчета для обмена в мессенджерах между дорожными рабочими.

## 👨‍💻 Структура файлов проекта

* `main.py` — Точка входа в FastAPI сервер, логика эндпоинтов и маршрутизация.
* `util/inference_utils.py` — Обертка над PyTorch-моделью для инференса и склейки слоев маски.
* `util/cv2_utils.py` — Геометрические расчеты и извлечение контуров (OpenCV), расчет длины/ширины трещин.
* `util/models/` — Архитектура сети DeepCrack.
* `web-deepcrack/` — Frontend SPA-приложение на базе Create-React-App.
* `pretrained_net_G.pth` *(не в репозитории)* — Веса обученной конфигурации сети.
